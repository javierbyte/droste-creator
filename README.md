# Droste Creator

Create recursive images with the droste effect.

[![droste-creator](docs-assets/screenshot.jpg)](https://javier.xyz/droste-creator)

## Development

```sh
pnpm install
pnpm dev
```

`pnpm build` writes the site to `dist/`. Pushing to `master` deploys it to the
`gh-pages` branch, which `javier.xyz/droste-creator` serves.
